# Li Donglin — Personal Portfolio

Personal portfolio website built with plain HTML, CSS, and JavaScript.

**Live site:** https://li-dlinseektime.github.io/personal-website/

## Pages

- `index.html` — Homepage with selected work and background
- `promptdeck.html` — PromptDeck case study
- `wilderness.html` — Urban Wilderness Perception research
- `about.html` — About page with photos and side projects
- `archive.html` — Earlier landscape architecture work (2022–2024)

## Stack

- HTML / CSS / JavaScript (no frameworks)
- Google Fonts (Inter)
- CSS custom properties for theming
- Intersection Observer API for scroll animations
- Deployed via GitHub Pages

## Notes

No build tools, no dependencies, no backend.
